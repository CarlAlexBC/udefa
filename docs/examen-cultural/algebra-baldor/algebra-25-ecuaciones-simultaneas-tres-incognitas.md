## Sub-lote 2 · Método de resolución de un sistema de tres ecuaciones con tres incógnitas (art. 306, p. 340)

### 6

De acuerdo con el libro de Álgebra, para resolver un sistema de tres ecuaciones con tres incógnitas, ¿cuál es el primer paso?

- A. Se combinan dos de las ecuaciones dadas y se elimina una de las incógnitas, con lo que se obtiene una ecuación con dos incógnitas
- B. Se suman las tres ecuaciones dadas para obtener una sola ecuación con tres incógnitas
- C. Se despeja una incógnita en las tres ecuaciones y se igualan entre sí
- D. Se elevan al cuadrado las tres ecuaciones y se restan

**Respuesta:** A
**Referencia:** Baldor, Aurelio (2019) *Álgebra*, Grupo Editorial Patria, Pág. 340
**Subtema:** Ecuaciones simultáneas tres incógnitas · método de resolución

Se combinan dos de las ecuaciones dadas y se elimina una de las incógnitas (lo más sencillo es eliminarla por suma o resta) y con ello se obtiene una ecuación con dos incógnitas.

### 7

En relación con el libro de Álgebra, para resolver un sistema de tres ecuaciones con tres incógnitas, ¿qué se hace con la tercera ecuación en el segundo paso?

- A. Se combina con cualquiera de las otras dos y se elimina entre ellas la misma incógnita que se eliminó antes, obteniéndose otra ecuación con dos incógnitas
- B. Se deja aparte hasta el final del procedimiento
- C. Se combina con las otras dos eliminando una incógnita distinta a la del primer paso
- D. Se divide entre las otras dos ecuaciones

**Respuesta:** A
**Referencia:** Baldor, Aurelio (2019) *Álgebra*, Grupo Editorial Patria, Pág. 340
**Subtema:** Ecuaciones simultáneas tres incógnitas · método de resolución

Se combina la tercera ecuación con cualquiera de las otras dos ecuaciones dadas y se elimina entre ellas la misma incógnita que se eliminó antes, obteniéndose otra ecuación con dos incógnitas.

### 8

De acuerdo con el libro de Álgebra, para resolver un sistema de tres ecuaciones con tres incógnitas, una vez obtenidas dos ecuaciones con dos incógnitas, ¿qué se hace en el tercer paso?

- A. Se resuelve el sistema formado por esas dos ecuaciones con dos incógnitas, hallando dos de las incógnitas
- B. Se combinan de nuevo con la ecuación original para eliminar otra incógnita
- C. Se representan gráficamente para hallar el punto de intersección
- D. Se suman para obtener el valor de la tercera incógnita

**Respuesta:** A
**Referencia:** Baldor, Aurelio (2019) *Álgebra*, Grupo Editorial Patria, Pág. 340
**Subtema:** Ecuaciones simultáneas tres incógnitas · método de resolución

Se resuelve el sistema formado por las dos ecuaciones con dos incógnitas que se han obtenido, hallando de este modo dos de las incógnitas.

### 9

En relación con el libro de Álgebra, en la resolución de un sistema de tres ecuaciones con tres incógnitas, ¿cómo se halla la tercera incógnita en el último paso?

- A. Sustituyendo los valores obtenidos en una de las ecuaciones dadas de tres incógnitas
- B. Restando entre sí las dos incógnitas ya halladas
- C. Sumando las tres ecuaciones dadas
- D. Aplicando la Regla de Sarrus a los valores obtenidos

**Respuesta:** A
**Referencia:** Baldor, Aurelio (2019) *Álgebra*, Grupo Editorial Patria, Pág. 340
**Subtema:** Ecuaciones simultáneas tres incógnitas · método de resolución

Los valores de las incógnitas obtenidos se sustituyen en una de las ecuaciones dadas de tres incógnitas, con lo cual se halla la tercera incógnita.
