En relación con el libro de Cálculo, según la definición del libro, ¿qué es una función ƒ de un conjunto D a un conjunto Y?

- A. Una regla que asigna un elemento único ƒ(x) ∈ Y para cada elemento x ∈ D
- B. Una regla que asigna uno o varios elementos de Y a cada elemento x ∈ D
- C. Una correspondencia que asigna a cada ƒ(x) ∈ Y un único elemento x ∈ D

- A. No; es posible que el rango no incluya todos los elementos del conjunto Y

**Respuesta:** A
**Referencia:** Thomas, G. B. (2015) *Cálculo. Una variable*, 13.ª ed., Pearson, Pág. 2
**Subtema:** Funciones · Función de valor real

### 11

En relación con el libro de Cálculo, ¿puede una función asignar el mismo valor de salida a dos entradas diferentes del dominio?

- A. Sí; pero cada elemento de entrada x está asignado a un valor único de salida ƒ(x)
- B. No; entradas diferentes siempre dan salidas diferentes
- C. Sí; y además una entrada puede tener dos salidas
- D. No; salvo en el valor x = 0

**Respuesta:** A
**Referencia:** Thomas, G. B. (2015) *Cálculo. Una variable*, 13.ª ed., Pearson, Pág. 2
**Subtema:** Funciones · Unicidad del valor de salida

Una función puede tener el mismo valor para dos entradas diferentes del dominio, pero cada elemento de entrada x está asignado a un valor único de salida ƒ(x).

> El corazón del concepto: dos entradas pueden dar la misma salida (muchas-a-una), pero una entrada nunca da dos salidas.
