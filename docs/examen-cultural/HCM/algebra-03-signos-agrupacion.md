## Sub-lote 3 · Equivalencia entre las cuatro formas (p. 59)

### 8

De acuerdo con el libro de Álgebra, ¿qué significación tienen el paréntesis angular, las llaves y el vínculo respecto del paréntesis ordinario?

- A. La misma significación, y se suprimen del mismo modo
- B. La misma significación, pero se suprimen de distinto modo
- C. Distinta significación, y se suprimen de distinto modo
- D. Distinta significación, pero se suprimen del mismo modo

**Respuesta:** A
**Referencia:** Baldor, Aurelio (2019) *Álgebra*, Grupo Editorial Patria, Pág. 59
**Subtema:** Signos de agrupación · equivalencia

El paréntesis angular [ ], las llaves { } y el vínculo o barra tienen la misma significación que el paréntesis ordinario y se suprimen del mismo modo.

### 9

De acuerdo con el libro de Álgebra, ¿por qué se usan signos de agrupación de distinta forma pero igual significación?

- A. Para mayor claridad cuando una expresión que ya tiene signos de agrupación se incluye en otro signo de agrupación
- B. Para distinguir las sumas de las restas dentro de una misma expresión
- C. Para señalar el orden en que fueron escritos los términos
- D. Para distinguir los términos semejantes de los que no lo son

**Respuesta:** A
**Referencia:** Baldor, Aurelio (2019) *Álgebra*, Grupo Editorial Patria, Pág. 59
**Subtema:** Signos de agrupación · equivalencia

Se usan estos signos, que tienen distinta forma pero igual significación, para mayor claridad en los casos en que una expresión que ya tiene uno o más signos de agrupación se incluye en otro signo de agrupación.

### 18

De acuerdo con el libro de Álgebra, ¿cómo se introducen cantidades dentro de un signo de agrupación precedido del signo menos?

- A. Se cambia el signo a cada una de las cantidades que se incluyen en él
- B. Se deja a cada una de las cantidades con el mismo signo que tengan
- C. Se cambia el signo únicamente a la primera cantidad
- D. Se cambia el signo únicamente a las cantidades positivas

**Respuesta:** A
**Referencia:** Baldor, Aurelio (2019) *Álgebra*, Grupo Editorial Patria, Pág. 61
**Subtema:** Signos de agrupación · regla para introducir

Para introducir cantidades dentro de un signo de agrupación precedido del signo menos (−) se cambia el signo a cada una de las cantidades que se incluyen en él.

> Las cuatro reglas del capítulo —suprimir con + y con −, introducir con + y con
> −— siguen el mismo patrón: **el signo + conserva, el signo − cambia**, se esté
> quitando o poniendo el paréntesis. Quien retiene esa idea no necesita
> memorizar las cuatro por separado.
